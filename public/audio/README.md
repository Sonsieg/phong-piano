# Portfolio music

`prelude-original.wav` is an original, procedurally composed piano-style miniature,
rendered by `scripts/render-prelude.mjs`. It uses additive synthesis, not a piano
recording, third-party samples, or an arrangement of another composition.

The score, rendering script and generated audio are dedicated to the public domain
under CC0 1.0 Universal: https://creativecommons.org/publicdomain/zero/1.0/

Run `node scripts/render-prelude.mjs` to reproduce the audio.
Add your licensed recordings here and register them in `src/config/playlist.ts`.
